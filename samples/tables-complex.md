# 复杂表格样例

## 对齐矩阵

| 左对齐 | 居中 | 右对齐 |
|:-------|:----:|-------:|
| a      | b    | c      |
| **粗体** | `code` | *斜体* |
| 中文格 | ✅ | 123.45 |

## 嵌套内容

| 功能项 | 是否支持 | 备注 |
|--------|:--------:|------|
| 管道表格 | ✅ | 行内 `code` 与[链接](https://example.com) |
| 合并单元格 | ❌ | GFM 语法不支持，属预期边界（§7 风险清单） |
| 任务列表 | ✅ | - [ ] 与 - [x] |

## 表格后文本

表格之间与之后应有正常段落，保证文档结构完整性。
