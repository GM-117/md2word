- **日期**：2026-10-05

## 1. 构建流程（D33 标准三步，本批无新缺陷）

1. `pnpm --filter @md2word/desktop build`（main/preload 最新编译，含 convert:progress 桥）；
2. 收窄 yml dmg arch → 单架构构建 ×2 → 还原 yml → Windows 构建：
   - `ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/ node scripts/dist.mjs --arm64`（yml dmg arch=[arm64]）
   - `ELECTRON_MIRROR=… node scripts/dist.mjs --x64`（yml dmg arch=[x64]）
   - `ELECTRON_MIRROR=… node scripts/dist.mjs --win`（yml 还原 [arm64, x64] 后）
   - 全程直接 `node scripts/dist.mjs` 调用（绕开 `pnpm dist --` 的 `--` 透传吞参坑，D33-①）；
3. 逐产物 `verify-dist.mjs`：11 项断言全过，**pandoc 架构与目标匹配**（arm64 dmg → arm64、x64 dmg → x64、win exe → PE x64）。

> 备注：还原 yml 时曾因 `arch: [x64]` 与 nsis 目标行同文导致一次全量替换断言失败（Python 脚本自身终止，未写入文件）——改带 `- target: dmg` 上下文精确匹配后恢复。属操作脚本问题非构建缺陷，记录备查。

## 4. 复现命令

```bash

# yml dmg arch 依序收窄为 [arm64] / [x64]，构建后还原
ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/ node scripts/dist.mjs --arm64
ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/ node scripts/dist.mjs --x64
ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/ node scripts/dist.mjs --win
node scripts/verify-dist.mjs release/mac-arm64/md2word.app
node scripts/verify-dist.mjs release/mac/md2word.app
node scripts/verify-dist.mjs release/win-unpacked --win
npx playwright test   # 含打包冒烟（release 产物存在时自动启用）
```
