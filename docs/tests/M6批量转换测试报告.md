## 5. 已知边界与设计说明

1. **符号链接不跟随**（文件与目录均跳过）：防扫描成环、防越出所选根目录；如需转换链接目标请直接选择目标目录。
2. **node_modules 排除**是对计划口径"排除隐藏/非 .md"的补充（依赖目录必非批量意图），已在计划 §8 决策 #5 记录。
3. **扫描进度**：批量行在整批返回前统一显示"转换中…"（与既有单作业一次返回的架构一致），队列头部有运行状态与取消按钮；逐文件流式进度留待后续增强。
4. **网页端重试**：bytes 模式下重试仅带该 .md 源文件本身，随文资源不重传（桌面端 path 模式无此限制，源文件始终在原位）。
5. **重名产物登记键**：桌面/网页统一 `N-` 前缀唯一化（`a.docx` → `2-a.docx`），open 与 download 共用，杜绝批量场景下载/打开错文件。
