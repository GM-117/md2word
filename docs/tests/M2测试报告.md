## 架构落实

- 传输适配器：`renderer/src/lib/transport.ts`（`ApiTransport` 接口 + HTTP 实现）——M4 换 IPC 时 UI 零改动。
- web-host：上传 → `.data/jobs/<uuid>/`（basename 防穿越）→ SerialQueue 串行转换 → 下载/打开端点（作业目录白名单）。
- 资源文件通道：**非 .md 附件作为作业资源保存**，md 内相对路径图片可直接内联（本轮 GUI 验收验证 test_img.png 内联成功）。
- 设置：`PUT /api/settings` 扁平 JSON 落盘 `.data/settings.json`；转换请求未带 options 时以持久化设置为缺省。

## 开发中发现并修复的缺陷

| # | 缺陷 | 根因 | 修复 | 回归 |
|---|---|---|---|---|
| D7 | Web 上传后图片缺失（tables=2/images=0，W_IMAGE_FETCH） | renderer 端把非 .md 文件过滤掉，资源未上传；pandoc 为缺失图生成单格 FigureTable 占位 | 一次作业提交全部文件：.md 转换 + 其他作资源保存 | E2E US1 断言「图片 1」 |
| D8 | 选项保存与转换竞态（US4 偶发无 TOC 警告） | patchOptions 的 saveSettings 为 fire-and-forget | convertFiles 前先 await 全量 saveSettings | E2E US4 稳定复现 3 次 |

| D10 | IAB 无 file chooser 上传能力（工具边界，非产品缺陷） | — | 改用 DataTransfer DropEvent 走真实 onDrop 路径验收 | GUI 截图 |
