# 平台产物同步重建报告（网页端 UI 调整同步至三平台安装包）

> 日期：2026-10-03 ｜ 触发：用户要求将网页端最新 UI 调整同步到 macOS app 与 Windows exe 安装包
> 前置：网页端两项调整已在 renderer 源码落地（提交 8d71b81 内）：①「代码块高亮风格」移至「覆盖同名输出」之后（选项面板末尾）；②「最近文件」功能整体注释隐藏（数据结构与后端契约保留，可随时恢复）。

## 1. 架构说明（为何需要重建产物）

renderer 为 Web/桌面共享代码（M4 既定决策：Electron 仅换传输层，UI 零改动），桌面应用从 `app://` 协议加载打包内置的 `Resources/renderer/`（构建期从 `packages/renderer/dist` 拷贝）。因此**源码层面功能天然同步，但已分发的安装包内嵌的是构建时的 renderer 快照**——必须以最新代码重新打包三平台产物。

## 2. 重建过程与发现的问题

| # | 问题 | 影响 | 处置 |
|---|---|---|---|
| 1 | `pnpm dist -- --arm64` 的字面量 `--` 会原样透传给 electron-builder，被 commander 当作选项终止符，**arch 过滤参数静默失效** | 按默认 target 构建了全部产物 | 直接 `node scripts/dist.mjs --arm64` 调用（绕过 pnpm `--` 转发） |
| 2 | **electron-builder 26 的 CLI `--arm64/--x64` 不覆盖 yml 中 per-target 的 `arch: [arm64, x64]`**：每次运行都会构建两个 dmg，而 `prepare-resources` 只暂存单一平台 pandoc → 产物出现**跨架构 pandoc 错配** | arm64.dmg 内一度装入 x64 pandoc（反之亦然） | 临时收窄 yml dmg arch 为单架构分三次构建（构建后还原 yml）；**D33 记录在案** |
| 3 | verify-dist 既有「pandoc 可执行 --version」检查**抓不到架构错配**：x64 二进制在 arm64 mac 上可经 Rosetta 正常执行并输出正确版本 | 检查盲区 | verify-dist.mjs 增加「pandoc 架构与目标匹配」断言（mac 用 `lipo -archs`，win 解析 PE machine 字段），检查项 10 → 11 |
| 4 | 网络原因导致 electron 下载超时（GitHub 直连不稳，2026-10-03 晚间复现两次） | 构建中断 | 沿用镜像方案 `ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/` 后稳定 |

## 4. 结论与建议

- 三平台安装包已与网页端 UI 完全同步，可继续按 [M4-冒烟清单](M4-冒烟清单.md) 执行 Windows 干净环境人工冒烟（W1–W7）。
- **遗留建议（D33 收尾）**：后续可让 `dist.mjs` 在单架构参数下以 `-c.mac.target.0.arch=` 覆写或逐架构分批编排，消除「单次运行双架构产物污染」的隐患；verify-dist 的架构断言已能兜底拦截。
- 打包固定命令备忘（本机 macOS）：
  ```bash
  pnpm --filter @md2word/renderer build
  cd packages/desktop
  ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/ node scripts/dist.mjs --arm64   # 前提：yml dmg arch=[arm64]
  ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/ node scripts/dist.mjs --x64     # 前提：yml dmg arch=[x64]
  ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/ node scripts/dist.mjs --win     # yml 还原后亦可
  node scripts/verify-dist.mjs release/mac-arm64/md2word.app
  node scripts/verify-dist.mjs release/mac/md2word.app
  node scripts/verify-dist.mjs release/win-unpacked --win
  ```
