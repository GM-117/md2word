## 7. 缺陷与坑记录（D15–D24）

| # | 问题 | 修复 |
|---|---|---|
| D15 | pnpm 12 因 transitive `electron-winstaller` 未批准构建脚本而**整体拦截** electron postinstall，二进制未下载 | pnpm-workspace.yaml allowBuilds 增加 `electron-winstaller: true`；electron 下载改走 `ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/`（GitHub 直连过慢） |
| D16 | tsc build 未设 rootDir，产物落在 `dist/` 根而非 `dist/main/`，与 main 字段不符 | tsconfig.build.json 显式 `rootDir: "src"` |
| D17 | **file:// 加载 Vite ES module 产物被 CORS 拦截**（打包 UI 白屏，T1 失败现场） | 注册特权协议 `app://`（standard+secure+supportFetchAPI）+ protocol.handle 托管 renderer 产物（显式 MIME，含 text/javascript） |
| D18 | bootstrap 重复执行导致 `Attempted to register a second handler for 'app:health'`，窗口永不创建 | 去除重复 registerBridge 调用 |
| D19 | 下载锚点在 will-navigate preventDefault 后，Chromium 导航长期 pending：Playwright `click()` 挂起、页面状态被污染 | 改为 `md2word://` 特权协议 + attachment 响应走 Chromium 下载管线（页面不导航）；Electron 默认弹出原生保存对话框；E2E 用 `MD2WORD_DOWNLOAD_DIR` 确定性落盘 |
| D20 | electron-builder 的 bin 是 shell shim，`spawnSync('electron-builder')` 在 mac 上静默失败 | dist.mjs 改为 `spawnSync(process.execPath, [require.resolve('electron-builder/cli.js'), ...])` |
| D21 | `--win` 未隐含 x64，target 解析成 win32-arm64 报错 | resolveTarget：--win 时缺省 x64 |
| D22 | 双 spec 并行启动 Electron 相互干扰（单实例锁退出） | playwright.config `workers: 1`（应用级测试串行） |
| D23 | ESLint 扫描 release/ 内打包后的 renderer bundle 报大量 no-undef | eslint ignores 增加 packages/desktop/{release,resources,build} |
| D24 | Playwright `setInputFiles` 传入真实路径 → 桌面端按真实路径模式转换，产物写源目录，撞上样例目录既有 .docx（`E_OUTPUT_EXISTS`）——**行为正确，测试夹具问题** | E2E 改用干净目录副本；该意外恰好验证了覆盖开关与失败路径 UI |

## 8. 安全与合规核对（Electron 官方清单 + §2.4）

- [x] `contextIsolation: true`、`nodeIntegration: false`、`sandbox: true`（预加载仅 contextBridge/ipcRenderer/webUtils）
- [x] `setWindowOpenHandler` 全拒（md2word://log 转交处理器后拒绝）；`will-navigate` 仅放行 md2word://
- [x] 权限请求全拒（setPermissionRequestHandler）；单实例锁；无远程内容加载
- [x] IPC 白名单集中注册于 bridge.ts；open:path 白名单 = 作业注册表登记产物；settings:set 校验与 web-host 同构
- [x] open/path 防穿越：注册表键为 basename，用户输入不参与路径拼接（单测锁定）
- [x] pandoc 独立子进程（arm's length）；THIRD-PARTY-LICENSES.md 随包（GPL-2.0 全文 + github.com/jgm/pandoc + 版本 3.12）；`PANDOC_PATH` 通道保留
- [x] 渲染层 CSP（script-src 'self'；img/connect 受控）

## 9. 与任务计划的偏差（均已在计划文档 §3 声明或本报告补充）

1. 计划 §M4-3 预想"导航拦截 + 存盘对话框"承接下载锚点 → 实际演进为 **md2word:// 特权协议 + attachment 下载**（D19 的正确解），日志导出仍走拦截 + 存盘对话框。对外语义不变："下载 .docx" = 保存副本（生产弹原生保存对话框）。
2. 体积实测高于估算（§2 表），属数据修正而非决策变更。
3. electron-winstaller allowBuilds、workers:1 等工程细节不涉计划范围。
