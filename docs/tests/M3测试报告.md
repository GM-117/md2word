## 分层测试结果

**core（88 例回归 + 模板激活验证）：** 黄金样例 10 例在"内置中文模板为默认"下全部通过——样式统计断言
（Heading/SourceCode/Compact 等命名样式）与模板切换正交，验证模板仅改字体字号不改样式命名。

**web-host API（18 例，其中新增 7 例）：**

| 用例 | 断言要点 |
|---|---|
| GET /api/templates | 内置项在位且 valid、pandocDefault 可选、defaultTemplate=builtin-zh |
| POST 合法模板 | 导入成功、列表出现且 valid |
| POST 缺样式模板 | 400 + missingStyles 含 Source Code + 不落库 |
| POST 非 docx | 400 |
| defaultTemplate=用户模板转换 | dc:title=集成测试标题、dc:creator 含测试员、styles.xml 含 SimSun（模板链路生效） |
| defaultTemplate=pandoc-default 转换 | styles.xml **不含** SimSun（pandoc 原生回退） |
| DELETE | 移除 + 默认回退 builtin-zh |

**Playwright E2E（7 例，新增 2 例）：** 模板下拉含"内置中文模板"、导入无效模板 UI 提示"缺少必需样式"；元数据填写 → 转换 → 下载 → 解包断言 dc:title/dc:creator。

## 开发中发现并修复的缺陷

| # | 缺陷 | 根因 | 修复 | 回归 |
|---|---|---|---|---|
| D11 | pandoc-default 选择不生效（仍注入中文字体） | resolveTemplate 的 pandoc-default 分支未短路，回退到内置模板；且 core 层 `referenceDocx=undefined` 也会自动补内置模板 | 显式导出 pandoc 默认模板为缓存文件（`--print-default-data-file`）传入，三种模板选择统一为路径语义 | web-host API 专项用例 |
| D12 | 导出的 pandoc 默认模板损坏（E_TEMPLATE_INVALID） | `runPandoc` stdout 按 utf8 字符串收集，二进制 zip 被解码损坏 | RunResult 新增 `stdoutBytes: Buffer`（二进制输出必须用字节通道） | core 单元回归 + API 用例 |
| D13 | e2e fixture 写入错位（工具层） | shell cwd 漂移 | 绝对路径重建 | E2E 通过 |

## 新增工具与产物
